# Security policy

Nexus is a personal/demo application with optional local encryption and cloud sync. Its current controls, threat model, known limitations, and release boundaries are documented in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Please do not post credentials, tokens, private financial data, or an exploitable vulnerability in a public issue. Use a private GitHub Security Advisory for this repository when available, or contact the repository owner through their GitHub profile to arrange a private report.

Include the affected version or commit, reproduction steps using synthetic data, impact, and a suggested mitigation when possible.

## Disclosure

This project does not currently promise a formal response-time SLA or a supported production security program. The repository is explicitly scoped as personal/demo until the release blockers in [docs/RELEASE_BLOCKER_REGISTRY_2026-09-12.md](docs/RELEASE_BLOCKER_REGISTRY_2026-09-12.md) are addressed.
